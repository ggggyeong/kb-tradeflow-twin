# 합성 예시와 검증 기록

최종 확인: **2026-09-08**. 자동 테스트 **151개 통과**, 실제 gpt-5-nano Flex 실행의 자동 확인 **10/10개 통과**. 한 합성 거래의 연결 검증이며 일반적인 금융 정확도나 업무 절감률 평가가 아니다.

## 어떤 입력을 썼나요?

`data/fixtures/tradeflow_example/`에 가상 Booking·송장·B/L과 금융일정 엑셀을 두었다. 송장 이미지 PDF는 텍스트 레이어가 없어 실제 RapidOCR를 거친다. 회사·거래값은 합성이며 실제 운송·결제 문서가 아님을 표시했다.

| 항목 | 기대값 | 실제 확인 |
| --- | --- | --- |
| 문서번호 | INV-DEMO-001 / BL-DEMO-001 / BK-DEMO-001 | 엑셀 거래정보와 연결 |
| 입금일 | 실제 선적 9월 21일 + 30일 = 10월 21일 | 코드 계산 일치 |
| 대출 만기 | 10월 15일 / 6일 먼저 | 충돌 |
| 선물환 매도 | 10월 16일 / 5일 먼저 | 충돌 |
| 공급자 지급 | 10월 19일 / 2일 먼저 | 충돌 |
| 다른 거래 | OTHER-LOAN | 분석 제외 |

Booking 예정 출항일 9월 18일과 B/L 발행일 9월 22일을 입금 계산 기준으로 쓰지 않는다. 수출채권 보유·거래 연결·선물환 매도 방향은 합성 입력의 확인 가정이다.

## 실제 LLM 실행

최종 실행 ID: `20260908T003526503773Z`

모델: `gpt-5-nano` / 실제 제공 등급: `flex`

전체 10회 호출 · 입력 14,294토큰 · 출력 2,929토큰

출력 토큰은 전체 호출·추론의 합계다. 호출당 출력 상한 2,000토큰과 다르다. 자동 재시도·모델 또는 요금 등급 전환은 하지 않았다.

자동 확인 10개: 문서 3종 분석, 예상 입금일, 세 충돌·차이, 모든 일정의 출처, 서비스 카드 3개, 핵심 원문 일치, 검토 주제만 사용, 이미지 송장 OCR, 보고서 생성, 실행 실패 없음.

최종 RAG 결과:

- 대출: 신한은행 상환·연체·연장 본문
- 선물환: 중국은행 매도 계약·손실·중도해지 본문
- 공급자: 신한은행 운전자금 자료 + HSBC 수출환어음 비용 + HSBC 수출채권 약정서
- 서비스 카드 3개, 자료별 발췌 정보 5개, PDF 보고서 3페이지
- 상태 `REVIEW_REQUIRED`: 텍스트 PDF의 위치가 근사값이라는 경고를 유지했다. 문서 세 개는 모두 ANALYZED이며 실행 실패와 구분한다.

이번 변경에서 실제 API 검증을 4차례 수행했다. 동일 조건 성공률 실험이 아니라 결과를 확인하며 바꾼 개발 검증이다.

1. 서비스·본문 주제별 검색은 통과했지만 금융 요약이 일반적이고 인용 범위보다 넓었다.
2. 출처 배열 제약을 추가한 실행은 금융 LLM 호출 단계에서 실패했다. 원문 데이터·키는 로그에 노출하지 않았고 실패를 정상 결과로 표시하지 않았다.
3. 지원되는 배열 길이 제약·서버 검증으로 바꿔 실행했지만, 자유 요약이 다른 자료의 조건을 섞는 문제가 남았다.
4. 자유 금융 요약을 제거하고 **자료별 핵심 원문 선택·문자열 검증**으로 좁혔다. 마지막 실행에서 모든 대상 자료와 세 서비스가 연결됐다.

초기 자유 요약에서 발견한 품질 문제를 자동 확인 10개가 탐지한 것은 아니다. 직접 결과를 읽어 확인한 한계이며, 이를 반영해 원문 발췌 중심 MVP로 바꿨다. 최종 문장 선택의 관련성·완전성도 별도의 금융 전문가 평가를 거친 것은 아니다.

## 자동 테스트

최종 전체 실행: **151 passed, 0 failed, 0 skipped**. 실제 로컬 OCR·E5·Chroma 통합 테스트 2개를 포함한다. 이 테스트의 LLM은 모의 응답이며 위의 실제 API 실행과 구분한다.

- 문서·엑셀 거래 연결, 모호한 결제조건, 날짜·통화·방향, 같은 날·미연결
- 잘못된 출처·페이지·해시·구간·주제, 원문에 없는 발췌
- 충돌 없음·근거 없음·미검토 본문의 검색 보류
- 같은 PDF 페이지의 다른 주제를 실제 Chroma 필터로 제외
- PDF 경계 문구의 누락·중복·순서 변경 시 색인 중단
- 도구 순서·호출 상한·외부 API 실패·키/추론 로그 제외

Ruff·포맷·Mypy도 확인했다. PyMuPDF의 외부 라이브러리 deprecation 경고 5개가 남아 있다. 연결 확인과 실제 금융 판단의 정확성은 다른 평가다.

## 재현

```bash
uv sync --extra dev --extra ocr
uv run python scripts/fetch_product_pdfs.py
uv run python scripts/build_product_vector_index.py
uv run python -m pytest -q
TRADEFLOW_LOCAL_MODELS=1 HF_HUB_OFFLINE=1 uv run python -m pytest -q
uv run ruff check app scripts tests
uv run mypy app

# .env에 새 키를 설정한 후 실제 유료 실행
uv run python scripts/run_example.py --live
```

기본 테스트만 실행하면 로컬 모델 테스트 2개는 생략된다. 공개 저장소를 새로 복제한 뒤에는 공식 PDF·로컬 모델·Chroma 색인을 직접 준비해야 한다.

최신 결과는 `output/example/live-result.json`, 실행별 기록은 `output/example/live-runs/`다. 합성 예시의 도구 인자·토큰·모델/등급만 기록하며 API 키와 비공개 추론은 저장하지 않는다. 최신 보고서 경로는 실행마다 교체되므로 과거 JSON이 과거 PDF까지 보존한다는 뜻은 아니다.

보고서와 설명서의 모든 페이지를 렌더링해 배치를 확인했다. 공개 설명서는 은행 원문 발췌를 포함하지 않는다. 공식 PDF·색인·모델·발췌 보고서는 로컬 전용이며 [자료 이용 주의사항](rag-corpus-guide.md)을 따른다.
